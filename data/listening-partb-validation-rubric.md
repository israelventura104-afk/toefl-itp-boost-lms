# Listening Part B — validation rubric

**Section:** TOEFL ITP Listening · Part B (long campus conversations)  
**Asset IDs:** LIST-0101 … LIST-0150  
**Pass rule:** average ≥ **4.0** and no dimension < **3**.  
**Bank policy (2026-09-16):** existing class-bank Part B items LIST-0106 … LIST-0115 stay as authored; new/rewritten items use this rubric.

## How dialogues are written

1. Clear **campus scenario** (advisor, office, roommate, service desk, etc.).
2. **2 speakers + narrator** intro/outro.
3. About **8–10 dialogue turns**: problem → detail → option/constraint → decision or next step.
4. Natural spoken English (contractions OK); university vocabulary; **no ETS wording**.
5. **4 questions** in audio order: Main Idea → Detail → Inference/Attitude → Detail or Function.
6. Distractors include at least one **same words / wrong meaning** trap.
7. Schema: `topic`, `setting`, `speakers`, `narrator_intro`, `dialogue[]`, `narrator_outro`, `questions[]`.

## Dimensions (score 1–5)

| # | Dimension | What “5” looks like |
|---|-----------|---------------------|
| 1 | **ITP Part B format** | Narrator + 2 speakers; 4 questions; A–D options; clear intro/outro |
| 2 | **Dialogue authenticity** | Realistic campus talk; natural turns; not textbook stiff |
| 3 | **Answerable from audio** | Every key is supported by what is said (no outside knowledge) |
| 4 | **Question-type mix** | Main idea + detail + inference/attitude (function OK as 4th) |
| 5 | **Distractors** | 3 plausible traps; ≥1 repeated-word wrong-meaning distractor |
| 6 | **Explanations** | Why correct + common mistake for each question |
| 7 | **Audio-ready script** | Speaker labels clean; spoken length roughly **45–90 seconds** |

## Batch notes

- Prefer **4 questions × 1 conversation** per asset ID.
- Topics should not near-duplicate another Part B item already in the bank.
- `ready_for_practice` only when script + questions pass this rubric **and** normalized `audio.mp3` exists.

# Structure & Written Expression — validation rubric (TOEFL ITP Level 1)

**Section:** TOEFL ITP · Structure and Written Expression  
**Use:** Guided practice, mocks, and **strategy class** drills (publish gate). Free demos may stay lighter.  
**Grounding (ETS):** This section measures recognition of language appropriate for **standard written English**.  
- **Structure (Sentence Completion):** incomplete sentence → choose the **one** word/phrase (A–D) that best completes a grammatically correct sentence. Topics are **general academic**.  
- **Written Expression (Error Identification):** sentence with **four underlined** parts (A–D) → identify the **one** underlined word/phrase that **must be changed** for the sentence to be correct.  
Source traits: ETS TOEFL ITP test content / Level 1 Section 2 sample directions (official).  
**Pass rule:** average ≥ **4.0** across scored dimensions **and** no dimension < **3**.  
**Originality:** all stems/options are original — never copy ETS / commercial copyrighted items.

---

## A. Sentence Completion (Structure)

### Dimensions (score 1–5)

| # | Dimension | What “5” looks like (ITP-aligned) | Reject if… |
|---|-----------|-----------------------------------|------------|
| 1 | **Format** | Exactly one blank; exactly 4 options A–D; `correctKey` matches `correctAnswer` text; blank is one grammatical slot (word or short phrase) | Double blank; 3/5 options; key mismatch; options are full sentences when the blank needs a phrase/word |
| 2 | **ITP Structure authenticity** | Standard **written** academic English; campus/academic topic (science, history, education, environment, etc.); length/complexity like ITP incomplete sentences | Workplace TOEIC tone; slang; spoken idioms; children’s English; stem so long it becomes a reading item |
| 3 | **Single correct answer** | Only one option yields a fully grammatical, natural sentence; other three are clearly wrong under standard written English | Two defendable answers; “both could work” in careful reading |
| 4 | **Skill clarity** | `skill` / `subskill` name what the item truly tests (e.g. S-V agreement with *the number of*, not vague “grammar”) | Skill mislabeled; item tests two unrelated rules at once without a clear primary skill |
| 5 | **Distractors** | Plausible ITP traps: wrong number, wrong tense, wrong form, wrong voice, wrong clause marker, parallel break — not nonsense | Random wrong words; distractors that are impossible English with no learner logic |
| 6 | **Explanations** | States the rule; names the trap in `commonMistake` | Only translates the key; no trap named |

### ITP-like quality checklist (binary — all must be Yes)

- [ ] Stem reads like academic textbook English (not chat, not business email).
- [ ] Blank position is typical of ITP (mid/late clause; not a gimmick).
- [ ] Options are parallel in length/type (all verbs, all connectors, etc.).
- [ ] Correct option is not the only one that “looks long/smart.”
- [ ] No culture-specific trivia required outside the sentence.
- [ ] Difficulty 2–4 for class bank (avoid all-easy d=1 piles).

## B. Error Identification (Written Expression)

### Display standard (already agreed for this LMS)

- Continuous sentence with **four underlined spans** labeled A–D.
- Options show **letter + underlined phrase** (not letter-only).
- Feedback shows **letter + phrase** (e.g. `B. were asked`).

### Dimensions (score 1–5)

| # | Dimension | What “5” looks like (ITP-aligned) | Reject if… |
|---|-----------|-----------------------------------|------------|
| 1 | **Format** | Exactly four underlined parts A–D; exactly one is the error; options = the four phrases; `correctKey` is the erroneous span | Missing underline mapping; more than one real error; correctKey points to a correct span |
| 2 | **ITP Written Expression authenticity** | Academic written sentence; error is a **standard** grammar/usage fault (agreement, tense, form, parallel, article, pronoun, etc.) | Spoken register; punctuation-only “errors”; style preferences that are still grammatical |
| 3 | **One must-change error** | Changing only the keyed span fixes the sentence; other three spans are grammatical in context | Two spans both wrong; “error” is stylistic not grammatical |
| 4 | **Skill clarity** | Skill matches the real fault (e.g. Each + singular verb) | Ambiguous fault; skill name does not match the error |
| 5 | **Distractors (other underlines)** | The three correct spans look “tempting” (long NPs, nearby plurals) so learners may mis-hunt | Three underlines are obviously fine and only one looks odd → too easy / artificial |
| 6 | **Explanations** | Says what is wrong, what it should be, and the common hunt error | Only says “B is wrong” |

### ITP-like quality checklist (binary)

- [ ] Error type appears in real ITP Written Expression families (agreement, tense/aspect, word form, parallel, clause marker, article/determiner, pronoun, comparative, etc.).
- [ ] Underlines are contiguous meaningful chunks (not random mid-word).
- [ ] No double error in one sentence.
- [ ] Options are the exact underlined strings.

## C. Strategy-class publishing gate

For each strategy page (teach → demos → practice), every **demo** and **practice** item must:

1. Pass this rubric (avg ≥ 4.0, no dim < 3).  
2. Target **one** Strategy Bible skill (same rule as TOEIC: one strategy per session).  
3. Keep answer-letter balance across the practice set (~A–D even).  
4. Keep feedback **after submit** for practice sets (unless the page is an immediate-feedback drill by design).  
5. Stay **original** (no ETS wording).

**Demos / free intro:** may be lighter; guided + mock + strategy practice = validated only.

---

## D. Automatic reject flags

- `correctKey` ≠ option key of `correctAnswer`
- Two options equally grammatical
- TOEIC workplace register in a Structure stem
- Error ID with zero or 2+ real errors
- Options not parallel (mix of clauses vs single words without reason)
- Explanation that only restates the key with no rule
- Copyrighted / near-verbatim commercial stems
